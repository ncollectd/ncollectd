# NAME

**ncollectd-thermal\_throttle** - Documentation of ncollectd's thermal\_throttle plugin

# SYNOPSIS

	thermal_throttle-plugin thermal_throttle
	plugin thermal_throttle

# DESCRIPTION

The **thermal\_throttle** plugin collects thermal throttling events
from Intel processors that have built in automatic and adaptive thermal
monitoring mechanisms.
